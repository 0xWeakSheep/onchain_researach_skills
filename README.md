# onchain_researach_skills

Codex skill pack for onchain analysis across explorer APIs, SQL data platforms,
and notebook/reporting tools.

## Skills

- `onchain-analysis`: Route a wallet, token, protocol, flow, or dashboard task to the right platform skill.
- `arkham-intelligence-api`: Use Arkham Intel API concepts and endpoints for entity, address, flow, portfolio, transfer, token, and alert workflows.
- `etherscan-api`: Use Etherscan API V2 for EVM addresses, contracts, logs, token transfers, stats, gas, and verification workflows.
- `dune-analytics`: Use Dune SQL, Data API, Data Catalog, materialized views, pipelines, uploads, connectors, and dashboards.
- `hex-analytics`: Build Hex SQL/Python notebooks, data apps, integrations, AI-assisted analyses, and shared reports.
- `observable-notebooks`: Build Observable notebooks with JavaScript, SQL, Plot, Inputs, data attachments, imports, sharing, and embeds.
- `deepnote-notebooks`: Build Deepnote SQL/Python notebooks, AI analyses, integrations, schedules, APIs, apps, and team workflows.

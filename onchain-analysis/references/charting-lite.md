# Lightweight Charting Guidance

This file is retained as a compatibility pointer. Use `onchain-charting` for chart selection, data shaping, rendering route, and visual QA.

## Routing

- Read `onchain-charting/references/chart-selection.md` for chart type decisions.
- Read `onchain-charting/references/data-shaping.md` for chart-ready schemas.
- Read `onchain-charting/references/tool-routing.md` for AntV, Mermaid/FigJam, notebook, spreadsheet, or frontend rendering choices.
- Read `onchain-charting/references/visual-qa.md` before final delivery.

## Minimum Handoff

- Title must state metric, chain/scope, and timeframe.
- Axis labels must include units.
- Source, caveats, and unknown/unlabeled buckets must remain visible.
- Include a table when addresses, tx hashes, or exact rows matter.

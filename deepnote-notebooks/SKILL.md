# Deepnote Notebooks

## Overview

Use Deepnote when the desired artifact is an AI-assisted SQL/Python notebook, collaborative data project, scheduled analysis, API-triggered notebook run, or notebook-to-app workflow.

## Workflow

1. Decide whether the job is exploration, production notebook, scheduled check, data app, or API-triggered workflow.
2. Connect data through integrations, uploaded files, cloud files, or warehouse/database connections.
3. Use SQL blocks for queryable sources and Python blocks for transformation, modeling, API calls, and visualization polish.
4. Store secrets in Deepnote credentials/secrets, never in notebook code.
5. Use scheduling/alerts when freshness or monitoring matters; use API execution when an external system should trigger the notebook.
6. Keep charts practical: clear metric, time window, unit, source, and caveat.

## Common Tasks

- Build: projects, workspaces, SQL blocks, Python notebooks, notebook blocks, modules, environment configuration.
- Connect: integrations, warehouses, databases, cloud files, file uploads, GitHub imports, shared datasets.
- AI: Deepnote Agent, SQL generation, code completion/editing, visualization, error fixing, explanations, custom instructions.
- Operate: schedules, alerts, API execution, versioning, code reviews, app usage insights.
- Share: data apps, Streamlit apps, sharing, embeds, comments, real-time collaboration, permissions.
